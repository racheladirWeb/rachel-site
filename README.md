# אתר עו״ד רחל אדיר

אתר סטטי בעברית (RTL): כחול כהה וזהב לפי המיתוג של המשרד.

## מבנה

| נתיב | מה יש שם |
|---|---|
| `src/pages/` | העמודים: בית, אודות, ביטוח לאומי, דיני עבודה, צור קשר, נגישות, פרטיות, תודה, 404 |
| `src/partials/` | חלקים משותפים: כותרת, פוטר, טופס יצירת קשר, אייקונים |
| `src/layout.html` | תבנית בסיס משותפת לכל העמודים (head, SEO) |
| `src/assets/` | CSS, JS ותמונות מעובדות |
| `photos/` | התמונות המקוריות (לא נוגעים בהן) |
| `content/` | טקסטים מקוריים שהתקבלו מרחלי |
| `dist/` | האתר הבנוי (נוצר אוטומטית) |

## הרצה מקומית

```bash
node serve.mjs
```

ואז לפתוח בדפדפן: http://localhost:4321

## מה עוד חסר

- [ ] שעות פעילות (מסומן בצהוב בעמוד צור קשר)
- [ ] הסדרי נגישות פיזיים במשרד: מעלית, חניה (מסומן בצהוב בהצהרת הנגישות)
- [ ] רחלי צריכה לעבור על מדיניות הפרטיות ולאשר אותה (מסומן בצהוב)
- [ ] רחלי צריכה לאשר את הטקסטים שנכתבו עבורה: תחומי עיסוק, שאלות נפוצות, "למה לבחור בי", ובפרט את הפירוט של מה שהיא מטפלת בו
- [ ] לוודא מול כללי הפרסומת של הלשכה את האזכור של תפקיד היו״ר ושל ההתמחות בביטוח הלאומי
- [ ] מספר רישיון: אופציונלי, אפשר להוסיף לפוטר
- [ ] דומיין, ואחריו הגדרת `SITE_URL` (ראו בהמשך)

## העלאה לאוויר (Netlify)

1. לפתוח חשבון חינמי ב-netlify.com.
2. לחבר את התיקייה דרך GitHub, או להריץ `npx netlify deploy`. הגדרות הבנייה כבר נמצאות ב-`netlify.toml`.
3. ב-Netlify, תחת Forms → Notifications, להגדיר שליחת מייל ל-rachel@adir-s.co.il על כל פנייה חדשה.
4. אחרי שקונים דומיין: לחבר אותו תחת Domain settings, ולהוסיף משתנה סביבה `SITE_URL=https://הדומיין`. זה מפעיל canonical ו-sitemap.
